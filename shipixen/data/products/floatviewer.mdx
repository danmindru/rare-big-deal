## Product Overview

FloatViewer: Redefining Professional Image Viewing on macOS.

FloatViewer is a high-performance, floating image viewer designed exclusively for macOS. Moving beyond simple viewing, it integrates OCR, professional RAW decoding, and advanced color analysis into a seamless, borderless workflow. It is the ultimate desktop companion for designers, photographers, and developers.

Pro Features:
- Borderless Floating Window: Images stay on top of all windows for a clutter-free reference experience.
- Pro-Grade Performance: CATiledLayer rendering ensures smooth handling of 100MB+ images and RAW files.
- Smart OCR: Extract and copy text from any image instantly using the native Vision framework.
- Image Analysis: Pixel-perfect Color Picker, cluster-based Palette extraction, and real-time vImage Histograms.
- Image Comparison: Side-by-Side, Overlay, and Slider modes for precise visual auditing.
- Deep EXIF Insight: View 24+ metadata fields, including Camera, Exposure, and GPS data.
- Universal Formats: Full support for WebP, AVIF, PSD, AI, OpenEXR, and professional RAW files.
- Native Experience: Fully optimized for macOS gestures (pinch-to-zoom, fluid rotation, and swipe).

System Requirements:
- macOS 14.0 (Sonoma) or later.
- Universal Binary for Apple Silicon and Intel Macs.
