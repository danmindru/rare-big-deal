## Product Overview

WebDAV Lite is a lightweight macOS menu-bar application that instantly transforms any folder on your Mac into a WebDAV server for your local network. It is the perfect solution for seamless file access, document syncing, and high-speed media streaming to your iPhone, iPad, TV boxes (like Apple TV), and other network devices.

Key Features:
- One-Click Sharing: Select a folder and start sharing instantly—no complicated setup required.
- Menu Bar App: Lives entirely in your menu bar. Clean, lightweight, and keeps your Dock clutter-free.
- Standard WebDAV Protocol: Connect from macOS Finder (⌘K Connect to Server), the Files app on iPhone & iPad, Infuse, VLC, nPlayer, Cyberduck, or any other WebDAV-capable app.
- Built-in Web File Manager: Open the shared address in any browser to browse, search, preview, and download files — and with Pro, upload, rename, and organize them right from the web page. The page follows your app's language. No app needed on the other device.
- Authentication Support: Optional username/password protection with a built-in random password generator.
- Smart File Filtering: System clutter (.DS_Store, Thumbs.db, AppleDouble files) is always hidden automatically. Custom patterns (.git, node_modules, .env) can be added manually — a Pro feature with one-click Quick Add.
- Universal Binary: Built natively for optimal performance on both Apple Silicon and Intel-based Macs.

How It Works:
- Viewing, searching & downloading: open the address in any web browser — free forever. Search your whole share, preview photos, videos, music, PDFs, and Markdown, and download files or entire folders as ZIP.
- Uploading & editing: unlock Pro, then manage files right in the browser — or connect with any WebDAV client. On a Mac, press ⌘K in Finder; on iPhone/iPad, use Files → Connect to Server.

Free Tier:
- Read-only WebDAV sharing — browse, download, and stream files to any device on your network.
- Includes optional username/password protection.

Pro Tier (one-time in-app purchase):
- Read & Write Access — upload, edit, and delete files from any WebDAV client (Finder, the Files app, Infuse, Cyberduck), with LOCK/UNLOCK compatibility for Infuse and other media players.
- HTTPS/TLS Encryption — secure your connections with custom certificates.
- Custom File Exclusion Filters — exclude any pattern beyond the automatic system defaults.

Requirements:
- Requires macOS 14.6 (Sonoma) or later
