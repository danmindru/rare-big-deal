## Product Overview

Stop wasting time typing the same things over and over. Snippety is a powerful text expander and snippet organizer designed to automate your workflow. Instantly access reusable templates for messages, documents, emails, code fragments, developer scripts, marketing details, and more - anywhere you type, paste directly from your keyboard.

Snippety integrates seamlessly with every app and text field. Use the dedicated Snippety Keyboard to expand your shortcuts instantly while typing. Want to save something on the fly? Create new snippets directly from any selected text using the Share menu.

With native iCloud sync, your entire snippet library is always up to date across your iPhone, iPad, and Mac. Install Snippety on all your Apple devices for a seamless and unified typing experience.

Seamless Integration:
- Dedicated Snippety Keyboard to let you access your snippets wherever you type. 
- Snippety Keyboard lets you easily switch between typing and expanding keywords. Select Snippet Expander, type a predefined keyword, and the snippet will expand automatically.
- Snippety Keyboard supports QWERTY, QWERTZ, AZERTY, and Dvorak layouts, allowing you to search snippets and fill placeholders directly from the keyboard.
- Share menu extension to create text snippets from any application.
- Integration with Shortcuts app.
- Minimalistic and beautiful design adjusted to light and dark mode.

Smart Placeholders:
- Create reusable templates by replacing customizable parts with smart placeholders.
- Take advantage of 20 smart placeholders: auto-incrementing number, AI assistant, calculated date, calculated time, clipboard content, random value, hyperlink, note, selectable date, selectable value, multiselect, selected text, snippet reference, text transformation, text variable, text variable reference, and multiline text variable. MacOS application supports also script, clipboard history, and file content placeholders.
- Avoid repeating the same parameters, with Snippety you can insert the same value into multiple places of your template.
- Use conditional blocks to dynamically show or hide parts of your snippet based on provided conditions.
- Build reusable parts of your snippets and reference them in other templates.

AI Integration:
- Enable AI features in all your applications by using AI placeholders.
- Access AI directly from Snippety Keyboard without opening the app.
- Ask Snippety to generate templates and insert placeholders using AI computing power.
- Smart AI assistant placeholder is ready to perform any task for you using the selected text or clipboard content.

iCloud Collaboration:
- Share selected snippets with co-workers, friends, or across your personal devices, even if they use different Apple IDs.
- The new collaboration is built using native Apple technologies, ensuring your data remains secure and never passes through third-party servers.
- Control who can access each shared snippet and choose between read-only or write permissions.

Flexible:
- Syntax highlighting supporting 50+ formats.
- Rich Text (RTF), HTML, and Markdown support (with images).

Unlimited access:
- Sync your snippets seamlessly across Mac, iPhone, and iPad.
- Share snippets using secure links.

Snippety is free to download and use with up to 8 active snippets. Upgrade to Snippety Pro to unlock:
- Unlimited snippets & keyboard usage
- iCloud Collaboration
- Snippet version history
- Database import & export
- Shortcuts integration
- Custom AI API integration

NOTE: Snippety Keyboard works with snippets in any language, but the keyboard itself allows typing English letters + diacritics. Keyboard input is used to fill placeholders, search, or expand snippets by keyword, and these features are limited to the English alphabet. These limitations do NOT affect the app - only the Snippety Keyboard.
